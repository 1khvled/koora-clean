## 🌟 Key Features

* **🛡️ Built-in Popup & Ad Interceptor:** Custom iframe and DOM sandbox blocking spam popups, redirects, and third-party advertising trackers.
* **📱 Progressive Web App (PWA):** Installable on Android, iOS, and Desktop with offline caching via Service Workers.
* **⚡ Native HLS Streaming:** Low-latency video playback powered by `hls.js` with multi-server fallback.
* **📅 Match Center:** Live match timings, league standings, head-to-head match details, and goal notifications.

---

## 🛠️ Tech Stack

* **Frontend:** Semantic HTML5, Modular CSS3, Modern ES6+ JavaScript.
* **Streaming:** `hls.js` video player integration.
* **PWA:** Service Worker (`sw.js`), Web App Manifest.
* **Hosting:** Vercel.
